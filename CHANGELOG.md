# Changelog


## Current Changes

- New Feature: Added Female playable character (Mint from PTCG 2)
- QoL: "Continue Duel" is now the first option in the main menu, when available.
- QoL: The main menu cursor always starts at the top position.
- QoL: Shortened the warning when trying to load save data from the Diary while you have save data from a duel.
- QoL: Text Speed is set to 5 by default.
- QoL: Opening cutscene is quicker, and the first tutorial battle is optional.
- QoL: When asked for a duel, the default option is now "Yes". (The first tutorial battle still defaults to "No".)
- QoL: Common duel animations such as shuffling the deck, drawing cards, flipping the coin, and placing prize cards are quicker.
- QoL: Reduced the artifical AI "thinking" delay slightly.
- QoL: Added option to concede a duel by pressing B + Select while in the main duel menu.
